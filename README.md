# nautica-docs

[![CI](https://github.com/andresrabal005/nautica-docs/actions/workflows/blank.yml/badge.svg)](https://github.com/andresrabal005/nautica-docs/actions/workflows/blank.yml)

Web de Náutica Bahía: tienda y alquiler de material náutico en Puerto de Mazarrón.

## Funcionalidades

- Portada con la presentación de la empresa.
- Página de contacto.

## Requisitos

- Un navegador web moderno (sin servidor necesario para la versión estática).

## Cómo ejecutarlo en local

1. Clona el repositorio:
```bash
git clone https://github.com/andresrabal005/nautica-docs
cd nautica-docs
```

2. Abre `index.html` en el navegador.
